# Meu Controle — Controle Financeiro Pessoal

Projeto integrador de Front-End desenvolvido com HTML5, CSS3 e JavaScript.

## Como executar
1. Baixe ou extraia a pasta do projeto.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador. Se tiver a extensão Live Server, clique em **Open with Live Server**.

## Funcionalidades
- Cadastro de receitas e despesas.
- Validação dos campos do formulário.
- Cálculo automático do saldo, total de receitas e total de despesas.
- Filtro por tipo de movimentação.
- Busca por descrição ou categoria.
- Exclusão de movimentações.
- Interface responsiva para celular e computador.

## Observação importante
Os registros ficam somente na memória da página e são reiniciados quando ela é atualizada ou fechada. O enunciado enviado apresenta a persistência via localStorage riscada, por isso ela não foi incluída.

## Publicação no GitHub
1. Crie um repositório **público** no GitHub.
2. Envie todos os arquivos e pastas mantendo a estrutura.
3. Confira se o repositório está público — o enunciado informa que repositório privado resulta em nota zero.
4. Copie o link do repositório para a entrega.
